# Coding Practice

This repository contains my solutions to various Leetcode and coding interview problems, implemented in Java.

## Prerequisites

- **Java Development Kit (JDK) 21** or later
- **Apache Maven**

## Project Structure

The project is structured as a Maven project. Valid solutions are located in `src/main/java/org/tdnhat99`.

### Solved Problems

- **Arrays & Hashing**
  - `TwoSum.java`: Two Sum problem.
  - `ValidAnagram.java`: Valid Anagram problem.
  - `GroupAnagram.java`: Group Anagrams problem.
  - `KthLargestInArray.java`: Kth Largest Element in an Array.
  - `FirstRepeatingInArray.java`: First Repeating Element in an Array.
  - `SecondLargestInArray.java`: Second Largest Element in an Array.
  - `SortArray.java`: Sort an Array.
  - `MergeInterval.java`: Merge Intervals.
  - `TimeConversion.java`: Time Conversion.

- **Strings**
  - `LongestSubstringWithoutRepeatingChar.java`: Longest Substring Without Repeating Characters.
  - `ValidPalindrome.java`: Valid Palindrome.
    
- **Dynamic Programming / Greedy**
  - `BestTimeToBuyAndSell.java`: Best Time to Buy and Sell Stock.

## Getting Started

### Building the Project

To build the project and run tests, navigate to the project root directory and run:

```bash
mvn clean install
```

### Running

The project also contains a `Main` class which can be used as an entry point for testing specific solutions manually.
